---

## 🌟 أبرز مميزات التطبيق

1. **شاشة الافتتاح السوداء السينمائية بنظام الآلة الكاتبة (Typewriter Intro):**
   - واجهة سوداء مخملية فخمة تظهر فور فتح الموقع.
   - آلة كاتبة حية تكتب وتمسح عبارات أدبية رقيقة تصف جمال غزل ودلالها واستثنائيتها، وتخبرها أن هذا المكان صُمم خصيصاً لها.
   - زر مذهب للانتقال السلس إلى الشات أو التخطي الفوري.

2. **التصميم الملكي غير التقليدي (Ultra-Luxury Obsidian & Rose-Gold):**
   - لوحة ألوان مستوحاة من حجر الأوبسيديان الليلي المزين بتدرجات الذهب الوردي (**Rose-Gold**) والجمشت.
   - أسلوب زجاجي داكن ناعم (**Dark Glassmorphism**) مع ظلال سديمية عائمة.
   - خطوط عربية فاخرة ومريحة للقراءة (`Alexandria` للعناوين و `Tajawal` للمحادثات و `Amiri` للعبارات الأدبية).

3. **شخصية وذكاء عاطفي عميق (غير مبتذل):**
   - مدعوم بأقوى نموذج ذكاء اصطناعي عملاق (`openai/gpt-oss-120b`).
   - نبرة حقيقية تفهم المشاعر وتسمع ما بين السطور كصديقة وفية واعية، بعيداً عن المجاملات الرخيصة والمبتذلة.
   - مساندة متكاملة في: تنظيم الدراسة وتخفيف الضغط، كتابة الخواطر، الأفكار الإبداعية، والفضفضة والراحة النفسية.

4. **نظام التدوير الآلي لمفاتيح الـ API (Key Pool Rotation):**
   - يدعم التدوير التلقائي بين مفاتيح Groq API لتفادي حدود الاستخدام وضمان أعلى سرعة استجابة.
   - نظام محاكاة داخلي غني بالردود الأدبية كخط دفاع احتياطي حال انقطاع الإنترنت.

```text

```

## 🚀 كيفية التشغيل والاستخدام

### الطريقة الأولى: التشغيل عبر خادم Node.js المحلي (موصى بها):

1. تأكد من وجود ملف `.env` وضبط المفاتيح بداخله.
2. شغّل الخادم مباشرة بأمر:
   ```bash
   node server.js
   ```
   أو
   ```bash
   npm start
   ```
3. افتح المتصفح على الرابط:
   ```text
   http://localhost:3000
   ```

### الطريقة الثانية: التشغيل المباشر في المتصفح:
- يمكنك النقر المزدوج على ملف `index.html` في أي وقت ليعمل مباشرة في المتصفح بدون خادم.
